Örnek:

https://gocardstcg.com/set/riftbound-sfd

adresine yönleniyor.

Sitemap'ten çıkar:

* 302 URL
* 404 URL
* 410 URL
* noindex URL
* duplicate URL
* obsolete URL
* eski slug
* redirect edilen URL

Eğer sistemde:

OLD URL
→ NEW URL

mapping'i varsa sitemap doğrudan NEW URL üretmeli.

# 6. KARTIN GERÇEK SATIŞ FİYATI YOKSA

fake Offer oluşturma.

Bu durumda temiz:

Product

schema kullanılabilir.

Offer
+
availability

no price

Product
+
Offer
+
price
+
priceCurrency
+
availability
+
url

Product only
