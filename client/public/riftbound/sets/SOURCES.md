# Riftbound set marks

Riftbound and expansion marks belong to Riot Games. These small WebP images
are cropped from the English retailer marketing artwork distributed by UVS
Games, Riot's Riftbound distributor, for storefront promotion.

Source portal:
https://uvsgames.com/retailer-portal/page-uvs-retailer-portal-marketing-assets-riftbound

- `sfd.webp`: Spiritforged, `2026/01/EN-20260129T181719Z-3-001.zip`
- `unl.webp`: Unleashed, `2026/04/EN-20260414T155404Z-3-001.zip`
- `ven.webp`: Vendetta, `2026/06/EN_S4_Vendetta.zip`
- `rad.webp`: Radiance, `2026/09/EN-20260914T141458Z-1-002.zip`

Archive base: `https://uvsgames.com/wp-content/uploads/`

Only the mark area is retained, not release-date or availability claims.
Origins and Proving Grounds use the existing Riftbound brand mark.
Promotional groups use the brand icon with their actual set names rather
than fabricated expansion marks.
