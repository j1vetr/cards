Keep the card browsing area immediately after the hero Riftbound-only. Pokémon remains elsewhere on the site, but not as a choice in this showcase.

**Why:** The user first requested a Riftbound focus, then explicitly asked “Pokemon kısmını kaldırabilirsin şuan oradan”. This supersedes the earlier mixed-game tabs in this section.

**How to apply:** Keep actual card-detail navigation accessible by mouse, keyboard and touch, and do not let carousel gestures consume ordinary clicks. This is not permission to replace Pokémon's provider or catalog or remove its other homepage sections.

Match this showcase to the site's existing colors rather than introducing an unrelated gold/green palette. Use the actual Riftbound icon instead of a sparkle symbol. Short headings, subtitles and labels should start each word uppercase using Turkish casing and use proper punctuation.

**Why:** The user rejected the previous look as “çok ai” and not matching the site, explicitly corrected the lowercase second words in headings/subtitles, and requested a Riftbound icon instead of the perceived AI icon.

**How to apply:** Preserve source card names as printed. Apply the casing to authored showcase copy, including subtitle text, without adding decorative template-like messaging.
